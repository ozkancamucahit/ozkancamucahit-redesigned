Tests are usually described as a safety net. I have started to think of them as a design tool instead: a way to make the shape of a product explicit.

<!-- truncate -->

## The interface of a decision

When a function is difficult to test, that friction is often telling us something about its boundaries.

```ts title="TypeScript"
const result = await createProject({
  name: 'notes',
  visibility: 'private',
});

expect(result.status).toBe('created');
```

The best tests make tomorrow's code easier to read.
